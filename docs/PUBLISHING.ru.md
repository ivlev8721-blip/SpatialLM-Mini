## Состав публикации

Включены код, тесты, README на английском и русском, MIT-лицензия, протоколы и измерения, исходный текст с сохранённой лицензией Gutenberg и подготовленные токены. Числа в опубликованных JSON не пересчитывались и не заменялись.

Исключены локальное окружение, резервные копии, кэш токенизатора, результаты новых локальных запусков и тяжёлые веса моделей. Файл `data/subword16k/tokens.pt` — данные токенизации, не веса; он включён намеренно. `.gitattributes` сохраняет исходные байты текста на Windows, чтобы не нарушались контрольные суммы.

Перед первым push проверьте `git status --short` и `git diff --cached --stat`. Веса можно опубликовать отдельным выпуском позже; сейчас публичных ссылок на скачивание весов нет.

## Если репозиторий ещё не создан

1. Войдите в свой аккаунт GitHub и откройте https://github.com/new.
2. Выберите владельца `ivlev8721-blip`, имя `SpatialLM-Mini`, видимость Public.
3. Описание: `Small PyTorch language models with sparse geometric and hybrid attention; reproducible 16K-context experiments on an 8 GB GPU.`
4. Если загружаете готовую локальную Git-историю, создайте пустой репозиторий без автоматически добавляемых README, .gitignore и лицензии. Эти файлы уже подготовлены.
5. В подготовленном локальном каталоге проекта:

```powershell
git remote add origin https://github.com/ivlev8721-blip/SpatialLM-Mini.git
git push -u origin main
```

Если remote `origin` уже существует, сначала проверьте `git remote -v`; не добавляйте второй и не используйте принудительный push. Если репозиторий создан с начальным коммитом, не заменяйте его историю: согласуйте локальную и удалённую истории или загрузите подготовленное дерево поверх начального коммита.

Вход в GitHub для браузера, Git CLI и подключённого приложения может быть раздельным. Для обычного HTTPS-push используйте стандартный вход Git Credential Manager; пароли и токены не нужно помещать в исходники или отправлять в чат.

## После загрузки

- Проверьте отображение обоих README и ссылок на результаты.
- Откройте Actions и дождитесь CPU tests. Два CUDA-теста на CPU будут пропущены; это ожидаемо и не заменяет локальный GPU-опыт.
- В About можно добавить темы `pytorch`, `language-model`, `sparse-attention`, `geometric-attention`, `hybrid-attention`, `long-context`, `research`.
- Первый анонс должен описывать измеренный результат и ограничения. Ускорение 2,47× относится к этой реализации и этому опыту; отдельная польза геометрии ещё не установлена.
