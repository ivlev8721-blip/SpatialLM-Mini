# Проверка на естественном тексте

В проект добавлены гибридная архитектура и воспроизводимый эксперимент, который сравнивает её с пространственной моделью и Transformer. Предыдущие исходники и результаты сохранены. Результаты нового сравнения находятся в `NATURAL_RESULTS.md`, исходные измерения — в `runs/natural_v1/results.json`.

## Что изменено

`ModelConfig.architecture` теперь поддерживает `hybrid`. При `hybrid_every=2` и четырёх слоях порядок такой: пространственный → Transformer → пространственный → Transformer. Причинность сохраняется во всех слоях. `ff_dim` позволяет явно задать ширину FFN; значение по умолчанию сохраняет прежнее поведение `4*dim`. Существующие веса загружаются без изменения формы параметров. Проверка конфигов при resume нормализует новые необязательные поля, чтобы старые checkpoint продолжали работать.

`configs/hybrid.json` позволяет обучать гибрид обычным `spatiallm.train`. Например, на существующем демо-корпусе:

```powershell
Set-Location 'path\to\SpatialLM-Mini'
.\.venv\Scripts\python.exe -m spatiallm.train --config configs/hybrid.json --data data/demo.txt --out runs/my_hybrid
```

Это отдельный обычный запуск, не процедура сравнения ниже.

## Корпус

Jane Austen, *Pride and Prejudice*, [Project Gutenberg, книга 1342](https://www.gutenberg.org/ebooks/1342). Сохранён исходный UTF-8 файл с лицензией и служебными материалами: `data/pride_and_prejudice_raw.txt`. Для обучения извлечён текст от первой фразы романа до завершающего маркера Gutenberg; вступление и издательские материалы перед началом романа исключены. Переводы строк нормализованы в LF. Иллюстративные подписи внутри романа остаются частью корпуса.

Разделение последовательное по символам: первые 80% — обучение, следующие 10% — валидация, последние 10% — финальный test. Каждая часть независимо кодируется в UTF-8; окна не пересекают границы частей. Размеры и SHA-256 сохранены в `data/natural/manifest.json`. Нельзя ожидать, что повторная загрузка меняющегося сайта всегда даст те же байты: для точного воспроизведения используйте сохранённый raw-файл.

Повторить подготовку без сети в новый каталог:

```powershell
.\.venv\Scripts\python.exe tools/prepare_natural.py --raw data/pride_and_prejudice_raw.txt --out data/natural_rebuilt
```

Существующие каталоги скрипт не перезаписывает.

## Протокол сравнения

Одинаковы глубина (4), ширина скрытого состояния (128), головы (4), контекст (128 байт), batch (8), AdamW, learning rate `0.0006`, weight decay `0.01`, clipping `1.0` и FP32. TF32 выключен, включены deterministic algorithms. Модели обучаются с нуля, без dropout. Для каждого seed подаются одинаковые обучающие окна в одинаковом порядке. Предобученные веса не используются.

Параметры выровнены изменением ширины FFN: 628 у пространственной модели, 512 у Transformer, 570 у гибрида. Получается 842368, 842624 и 842496 параметров соответственно — расхождение менее 0.04%. Поэтому тест проверяет практические варианты с одинаковым бюджетом параметров, а не изолированный эффект замены только attention. Увеличенная FFN сама может влиять на качество.

Один запуск сохраняет два состояния:

- **Одинаковые шаги:** после 500 шагов, 512000 предсказанных байт на модель.
- **Одинаковое время:** первый завершённый шаг после 45 секунд накопленного времени обучения. Время включает выбор батча, передачу на устройство, forward, backward, clipping, AdamW и синхронизацию GPU. В него не входят прогрев, валидация, запись файлов и генерация. Это сравнение при одинаковом времени обучения, а не полном времени от запуска команды до завершения процесса.

Три seed — 42, 43, 44. Порядок моделей циклически меняется между seed, чтобы уменьшить влияние фиксированного порядка и прогрева устройства. Если оба порога не достигнуты, обучение продолжается до обоих. Число шагов при одинаковом времени зависит от нагрузки и скорости компьютера, поэтому побитное воспроизведение equal-time результата не обещается; состояние после 500 шагов воспроизводимо в том же окружении.

При оценке используются все полные непересекающиеся блоки из validation/test с одинаковыми целевыми позициями у всех моделей. Последние 100 возможных целевых байт validation и 19 test не входят из-за неполного блока. Loss усредняется по числу целевых байт, включая последний неполный batch. `test.loss` — средняя negative log-likelihood в натуральных логарифмах: меньше — лучше. Дополнительно сохраняются bits per byte и byte perplexity. Test не используется для выбора настроек, остановки или лучшей модели; бюджеты и параметры зафиксированы до основного запуска.

## Воспроизведение

Из корня проекта:

```powershell
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m spatiallm.experiment --device cuda --steps 500 --seconds 45 --seeds 42 43 44 --out runs/natural_repeat
```

При повторении нужен новый `--out`; имеющиеся эксперименты не перезаписываются. Не запускайте несколько GPU-экспериментов одновременно. Модуль работает и на CPU с `--device cpu`; длительность достижения 500 шагов при этом может существенно вырасти.

Доступны `--dim`, `--layers`, `--heads`, `--seq-len`, `--local-window`, `--batch-size`, `--lr`, `--weight-decay`, `--threads`. Полные фактические параметры каждого запуска сохранены в `protocol.json`. Для нового корпуса нужен каталог с тремя UTF-8 файлами `train.txt`, `validation.txt`, `test.txt`, передаваемый через `--data`.

## Сохранённые файлы

- `runs/natural_v1/protocol.json` — настройки, окружение, конфиги и хеши данных.
- `runs/natural_v1/results.json` — все 18 измерений, средние, стандартные отклонения и парные различия против Transformer.
- `<architecture>_seed<seed>/metrics.json` — измерения отдельной модели.
- `<architecture>_seed<seed>/equal_steps.pt` и `equal_time.pt` — веса для генерации и независимой проверки результатов.
- `<architecture>_seed<seed>/sample.txt` — пример генерации из последнего достигнутого состояния. Примеры не являются оценкой качества.
- `runs/natural_v1/experiment_run.log` — вывод основного запуска.

Эти экспериментальные `.pt` — **снимки для оценки и генерации**; они не содержат AdamW/RNG для resume через `spatiallm.train`. У обычного `spatiallm.train` полноценное продолжение обучения по-прежнему поддерживается. Пример генерации гибрида:

```powershell
.\.venv\Scripts\python.exe -m spatiallm.generate --checkpoint runs/natural_v1/hybrid_seed42/equal_time.pt --prompt 'Elizabeth ' --max-new-tokens 200 --temperature 0.8
```

## Границы вывода

Это небольшой предварительный эксперимент: один английский роман, короткий контекст, три seed и короткий бюджет обучения. Среднее и стандартное отклонение по трём seed не являются доверительным интервалом или проверкой статистической значимости. Не исследованы длинный контекст, несколько жанров, русский язык, большие модели, подбор learning rate отдельно для каждой архитектуры и оптимизированное геометрическое GPU-ядро. Для доказательства пользы именно координат понадобится дополнительная модель без геометрии, но с тем же графом связей и той же FFN.
