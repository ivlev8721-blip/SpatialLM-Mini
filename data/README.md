# Data provenance / Происхождение данных

| Path | Origin and purpose |
|---|---|
| `demo.txt` | Synthetic geometry descriptions generated by the project's `tools/make_demo.py`; repeated templates for a small pipeline demo |
| `pride_and_prejudice_raw.txt` | Pinned Project Gutenberg edition of Jane Austen's *Pride and Prejudice*, including the original notice/license |
| `natural/` | Fixed contiguous 80/10/10 character partitions, then UTF-8 encoded independently |
| `subword16k/tokens.pt` | Prepared GPT-2 token IDs for those same independently encoded partitions |
| `natural/manifest.json` | Source URL and raw/clean/split SHA-256 hashes |
| `subword16k/manifest.json` | Tokenizer version, vocabulary size, text hashes, token counts, and uint32 little-endian token hashes |

The 16K experiment contains 141,979 train, 18,537 validation, and 18,225 test tokens. No training window crosses a partition boundary. Evaluation uses the first 16,384 target positions of each held-out partition, equally for all architectures.

To recreate the text partitions without overwriting the pinned files:

```bash
python tools/prepare_natural.py --raw data/pride_and_prejudice_raw.txt --out data/natural_rebuilt
python -m spatiallm.subword16k prepare --text data/natural_rebuilt --data data/subword16k_rebuilt
```

`tokens.pt` is a PyTorch data container, not pretrained model weights. The loader uses `weights_only=True` and validates token sequence hashes. First-time tokenizer initialization requires internet access; `data/gpt2_cache/` is local and ignored by Git.

For exact byte hashes, Git must preserve the corpus bytes on Windows. The repository's `.gitattributes` disables line-ending conversion for the source and partition text files.

Corpus authorship and terms remain separate from the code's MIT license. Read [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) and the full notice inside the pinned Gutenberg source.

По-русски: в репозитории сохранены исходный текст, неизменённые части корпуса и подготовленные токены. `demo.txt` — повторяющиеся синтетические примеры для проверки работы, не независимый тест качества. Контрольные суммы находятся в manifest-файлах; исходная лицензия Gutenberg сохранена в полном тексте.
